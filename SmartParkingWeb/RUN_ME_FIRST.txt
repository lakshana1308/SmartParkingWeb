SMART PARKING WEB - COMPLETE PROJECT

1. Open this SmartParkingWeb folder in IntelliJ IDEA (the folder containing pom.xml).
2. Use JDK 17 or newer.
3. In IntelliJ Terminal, run: .\run.ps1
4. Open the localhost URL printed in the terminal.
5. Stop the server with Ctrl+C in the terminal.
